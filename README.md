Colour changing chop.Toe 
This coding exploration was created using TouchDesigner and data from the Week 11 CHOP exercise. It uses a Superquad SOP shape, with noise applied to create movement, and a Fractal SOP to generate the final form. The colour is controlled through a Mouse SOP, which is referenced in the lighting setup.I really wanted to experiment further with the different types of 3D shapes available in TouchDesigner, and the Superquad SOP helped me do this because it offers so many adjustable parameters that influence the shape's appearance. In combination with the Noise, Fractal, and Mouse SOPs, it created a dynamic and interactive final result.I had a lot of fun moving the mouse around and seeing how referencing the Mouse CHOP across different colour channels changed the possible colour outcomes. If I were to develop this project further, I would use the Mouse CHOP to also control the movement and shape deformation, maintaining the reactive qualities of the work while making the interaction more directly controlled by the mouse.

Pattern 2.toe
This coding exploration was created using TouchDesigner during Week 8 independent study and focuses on changes over time. This pattern is made from two tiles of the same revolving rectangular TOP shape. By flipping it on a second axis and reflecting certain parts, I was able to create two different effects using the same source. These were then combined using a Composite TOP.It was a really interesting idea to explore how the same shapes or TOPs could create completely different effects. It also allowed me to gain a better understanding of the variables for each command. The result provides a very interesting overall look to the exploration.

Scribble ball
This coding exploration was created in p5.js from the Week 6 independent study on translate and rotate. It is made up of multiple ellipse shapes. I created two translation variables and set them to move randomly between a set range according to the canvas size, placing the shapes using the shapeX and shapeY variables to control the position of each ellipse on the canvas.I then used rotate() to stagger the angle of each generated ellipse, creating a changing, scribbled effect. I really loved how this looked, and I thought it was a cool way to combine both translate and rotate.I am also very fond of the scribble aesthetic, as it aligns with hand-drawn art styles that use scribbles to build an image. This is something I would like to expand on further, restricting the scribbles to certain areas to gradually build a more recognizable image.

Random night loop
This coding exploration was created in p5.js from my Week 4 independent study on patterns and loops. I wanted to combine loops with randomisation to create a pattern with multiple meanings and constantly changing lines. Using a for loop and the variable high, I wanted all the lines to be parallel and run straight up and down, so I used the variable in the following code: line(high, shapeX + 150, high, shapeY + 50). When randomising colour, I also experimented with limiting the colours to a specific range within the colour wheel. I achieved this by not using the full 0–255 range for the colour values.I chose this coding exploration because it was the one that had the clearest vision and concept. It also demonstrated my ability to fully execute that vision using the skills I had developed. Additionally, it gave me more practice using randomisation within code. 

Noisy lazer
This coding exploration was created in p5.js from the Week 5 independent study on Perlin noise. I used a previous project, the random laser, and modified it to use Perlin noise instead. I also wanted the laser to look like it was lighting up a dark room, so I experimented with colour by making the background a darker version of the laser colour. I did this by restricting the colour range for the background values to 0–77 instead of 0–255 (the full range used for the laser), while keeping the increments the same for both the background and the laser so that they would change together.I chose this exploration because it gave me a very good foundational understanding of using colour within code, which I continued to use throughout almost all of my coding explorations. I also like the overall visual effect that it creates.
